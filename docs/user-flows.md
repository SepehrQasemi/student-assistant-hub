# User Flows

## Start a workspace

1. Open the application.
2. Create courses and optionally add calendar items.
3. Add supported local files to a course.
4. Export a backup after meaningful changes.

## Summarize a document

1. Open a stored file.
2. Extract its text locally.
3. Choose a summary mode.
4. The application scores concepts and source sentences deterministically.
5. Review the stored result and its source-version status.

## Generate and take a quiz

1. Select eligible course material.
2. The application builds questions from extracted text and ranked concepts.
3. Complete the quiz locally.
4. Review the score, answers, and stored attempt.
5. Regenerate when source fingerprints show that material changed.

## Backup and restore

1. Export the workspace from the application.
2. Store the file privately.
3. Validate and import it in another browser profile when needed.
4. Confirm courses, files, and study artifacts after migration.
